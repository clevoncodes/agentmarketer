## Next step: Admin and merchant dashboards

Oja does not currently have admin or merchant dashboards. The app is a storefront prototype with a static product catalog and demo bargaining flow.

Build the dashboards as the next product milestone:

- **Merchant dashboard:** let authenticated merchants manage their own products, prices, stock, and orders.
- **Admin dashboard:** let authorized admins review merchants, manage the marketplace catalog, and oversee orders and platform settings.
- **Access control and data:** add persistent storage and server-side role and ownership checks before exposing dashboard data or actions. Merchants must only be able to access their own records.
